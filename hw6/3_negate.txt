Domain: people
    P(x): person x is a programmer
    R(x): person x plays rugby
    D(x): person x has a dog
    M(x, y): person x is the manager of person y


In each of the following problems:
    - Express the statement in English, using the predicates above
    - Negate the statement, so that:
        - There is no negation to the left of a quantifier
        - There is no negation of a parenthetical ( ) expression
        - If your final negation contains a ∀ statement followed by an ⋁,
                rewrite it to use → instead of ⋁
    - Show your work for partial credit


1) ∀ x (P(x) → D(x))

Expressed in English:
* All programmers have a dog.



Predicate logic negation:
!(∀ x (P(x) → D(x)))
∃ x !(P(x) → D(x))
∃ x (P(x) & !D(x)) 

*    ∃((x: T) => (P(x) ⋀ ¬D(x)))

2) ∃ y (R(y) ⋀ ¬P(y))

Expressed in English:
* Some people play rugby but don't program.



Predicate logic negation:
!(∃ y (R(y) ⋀ ¬P(y)))
∀ y !(R(y) ⋀ ¬P(y))
∀ y (!R(y) V P(y))
∀ y (R(y) -> P(y))

*    ∀((y: T) => (R(y) → P(y))

3) ∃ x ∃ y (D(x) ⋀ M(x, y))

Expressed in English:
* Some people own dogs and are the manager of someone. 



Predicate logic negation:
!(∃ x ∃ y (D(x) ⋀ M(x, y)))
∀ x ∀ y !(D(x) ⋀ M(x, y))
∀ x ∀ y (!D(x) V !M(x, y))
∀ x ∀ y (D(x) → !M(x, y))

*    ∀((x: T) => ∀((y: T) => (D(x) → ¬M(x, y))))


///////////////////////////////////////////

4) ∀ x ∃ y (P(x) → M(x, y) ⋀ R(y))

Expressed in English:
* All programmers are managers of a rugby player.



Predicate logic negation:
!(∀ x ∃ y (P(x) → M(x, y) ⋀ R(y)))
∃ x ∀ y !(P(x) → M(x, y) ⋀ R(y))
∃ x ∀ y !(!P(x) V (M(x, y) ⋀ R(y)))
∃ x ∀ y (P(x) ⋀ !(M(x, y) ⋀ R(y)))
∃ x ∀ y (P(x) ⋀ (!M(x, y) V !R(y)))

*   ∃((x: T) => ∀((y: T) => (P(x) ⋀ (¬M(x, y) ⋁ ¬R(y)))))
